What a wonderful day for a release! The end of another three-month development cycle has arrived. A couple of weeks ago I released a release candidate, received a few issue reports — and the release became a little more stable.

Today I'm officially releasing **Thunder Engine 2026.3** 🚀

---

**🆕 What's new?**

**Engine:**  
🏷 Component tags — you can now assign tags and manage groups (#1321, #1322)

**Rendering:**  
✨ Bloom improvements — higher-quality glow (#1311, #1312)

**UI/UX:**  
🖼 Canvas component — a new starting point for UI rendering (#1325, #1326)  
📑 TabWidget container — tabs for convenient interface organization (#1302, #1316)

**Refactoring:**  
🔄 Resource UUID system — reworked for greater flexibility (#1317)  
🧩 Prefab workflow improvements — a more intuitive workflow (#1297, #1299)
